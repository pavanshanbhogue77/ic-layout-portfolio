# Pavan U Shanbhogue — Layout & Certificate Portfolio

A lightweight GitHub Pages portfolio containing only:
- Custom IC layout images
- Technical certificates

No project descriptions or project repositories are included in this version.

## Publish with GitHub Pages
1. Upload these files to your GitHub repository.
2. In GitHub: Settings → Pages.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`.
5. Save and wait for the Pages URL to become available.

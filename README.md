## Publish with GitHub Pages

1. Create a new GitHub repository, for example `ic-layout-portfolio`.
2. Upload everything in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.
5. GitHub will provide the Pages URL. Put that URL on the resume as **Portfolio**.

No build system is required: the site is plain HTML/CSS.
